## 📌 Course & Curriculum Overview

This repository provides a comprehensive 13-part curriculum designed to build a rock-solid foundation in Python programming tailored specifically for Artificial Intelligence, Machine Learning, Data Science, and Software Development.

---

## 📚 13-Chapter Curriculum Modules

```
Chapter 1: Python Basics, Variables, & Data Types
Chapter 2: Strings & String Manipulation Functions
Chapter 3: Lists, Tuples, & Sequence Operations
Chapter 4: Dictionaries, Sets, & Key-Value Data Structures
Chapter 5: Conditional Expressions & Decision Making (if-elif-else)
Chapter 6: Loops (for, while, break, continue, pass)
Chapter 7: Functions, Arguments, Recursion, & Lambda Functions
Chapter 8: Object-Oriented Programming (OOP) - Classes & Objects
Chapter 9: Inheritance, Polymorphism, & Dunder Methods
Chapter 10: File Input/Output (I/O) & Context Managers
Chapter 11: Exception Handling, Try-Except Blocks, & Custom Errors
Chapter 12: Advanced Python 1 - Decorators, Generators, & Iterators
Chapter 13: Advanced Python 2 - Modules, Packages, Virtual Envs, & AI Setup
```
